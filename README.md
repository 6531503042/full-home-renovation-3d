# Unified Full-Home Japandi 3D Renovation Studio (20.16 ตร.ม.)

โมเดลจำลอง 3D สถาปัตยกรรมแบบเปิดโล่ง (Open-Plan Unified 3D Studio) รวม 2 ห้องเชื่อมต่อกันจริง 100%:
1. **โซน A: โถงนั่งเล่น & เวิ้งบันได (Lounge & Hallway)**: กว้าง 2.80 × ยาว 4.20 × สูง 2.50 ม. (11.76 ตร.ม.)
   - บันไดพับกลับ 180° ไร้ผนังกั้นขวา (Open Riser 3 ขั้นล่างเดินเข้าสู่ชั้นลอย -X, บันไดขั้น 3 พุ่งสวนตรงออกมาหาโถง +X)
   - ราวลูกกรงไม้กลึงสั้นข้างบันได + ระแนงไม้สูงถึงฝ้าแนวทางเดิน
   - ผนังระแนงไม้สัก 1.60ม. พร้อม TV 55"
   - Sofa Bed ผ้านาโนกันขนแมว และชุดไฟห้อยหยดน้ำสีส้ม

2. **โซน B: ห้องนอน & Dev Studio**: กว้าง 2.80 × ยาว 3.00 × สูง 2.50 ม. (8.40 ตร.ม.)
   - กำแพงฝั่งหน้าต่างภายนอกเป็นระนาบเดียวกันตลอดแนวตัวบ้าน 2.80ม.
   - เชื่อมต่อผ่านประตูบานสวิงลูกฟักข้างทีวี (Z = 0.00ม.)
   - โต๊ะทำงาน Dev Studio จอคู่บนขาจับ Gas Spring 360°
   - โหมด Bed Cinema: หมุนสวิงจอที่สอง 90° ข้ามไปดูหนัง 4K ฝั่งเตียงนอน 3.5 ฟุต
   - โต๊ะเครื่องแป้งมินิมอล + กระจกเงาบานใหญ่
   - สลับโหมด Before (ห้องเดิม) ↔ After (รีโนเวท Japandi) ได้ทันที

**งบประมาณรวมทั้งบ้าน (BOQ)**: 50,370 ฿ ครบ 17 รายการ
